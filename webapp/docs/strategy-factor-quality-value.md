# 퀄리티 + 밸류 + 보수적 투자 팩터 전략 — 보류(미구현)

> **상태: 미구현.** 이 전략은 종목별 **재무제표 데이터**가 필요한데, 현재 시스템에는 가격(OHLCV)
> 데이터만 있어(`stockdailyprices`, `stock.sector`는 비어 있음) 백테스트가 불가능하다. 아래는 스펙만
> 기록해 둔다. 재무데이터 파이프라인이 갖춰지면 착수한다. (업로드 문서 원본 기준 요약)

## 왜 지금 못 하나 (데이터 공백)

필요한데 시스템에 **없는** 데이터:

- 재무: EBIT, EV, FCF, 시가총액, 장부가치(book value), GP(매출총이익), 총자산, 순부채/부채비율,
  ROIC, accruals(발생액), 자산증가율, 설비투자(capex) 증가율, 순주식발행량
- 분류/유니버스: 업종(sector) 분류, 시가총액·거래대금 랭킹, **상장폐지 종목 포함**(생존편향 제거),
  재무제표 **실제 공시일**(point-in-time, 60~90일 지연 반영 — 미래정보 차단)

가격만으로는 위 팩터를 계산할 수 없다. 별도 재무데이터 수집·모델·ingest 구축이 선행돼야 한다.

## 전략 스펙 (구현 시 참조)

### 1순위 — 퀄리티·밸류·보수적투자 종합 팩터
- **밸류 점수**: EBIT/EV, FCF/EV, B/P (높을수록 저평가)
- **퀄리티 점수**: GP/A, ROIC, FCF/A (가점) / Leverage, Accruals (감점)
- **보수적 투자 점수**: Asset Growth, Capex Growth, Net Share Issuance (과도하면 감점)
- **유니버스**: 시총 상위 300~500, 거래대금 하위 20% 제외, 관리·거래정지·자본잠식 제외, 금융업 별도/제외,
  재무 공시 후 60~90일 지난 데이터만
- **전처리**: 각 지표 1%/99% Winsorizing → **업종 내 Z-score**(업종중립) → 세 점수 합산
- **선정**: 종합점수 상위 10~15%(예 40~60종목)
- **비중**: 동일가중, 종목당 최대 3~4%, 업종 ±5%p, 그룹/테마 상한
- **리밸런싱**: 분기 1회 + **히스테리시스**(신규 매수 상위 15% 진입, 기존 매도 상위 30% 밖 이탈)

### 2순위 — 위 + 단기 잔차반전(Residual Reversal)
- 퀄리티·밸류 상위 30%만 후보 → 각 종목 최근 5일 **업종조정 수익률**(또는 시장·업종 베타 제거 잔차) 계산
  → 잔차수익률 최저(과매도) 종목 매수 → 5~20거래일 보유 → 보유만료/잔차정상화로 청산. 대형·고유동성만.

### 백테스트 필수 조건 (원문 강조)
생존편향 없는 데이터(상폐 포함), 실제 공시일 반영, 거래정지·상하한가 반영, 수수료·슬리피지 반영,
15~20년 이상 여러 국면, 마지막 20~30%는 완전 표본외(out-of-sample), 다른 시장(한/일) 방향성 확인,
과최적화 금지.

## 착수 시 필요한 선행 작업 (요약)
1. 재무데이터 소스 확보(PIT 재무 + 상폐 + 업종 + 시총) — 무료 소스로는 난제.
2. 모델·ingest 신설(예: `financials` 컬렉션).
3. 팩터 계산·Winsorize·업종 Z-score·랭킹·히스테리시스 순수 엔진(테스트 가능) + 분기 리밸런스 러너.
4. 기존 백테스트 UI 에 팩터 전략 탭 추가.
