# 〈에테르니아의 추락〉 씬 텍스트 서식 규약

씬 본문(`body[]`)·선택지 라벨(`label`)에 공통 적용. 렌더러:
`src/lib/web-adventure/play/render-inline.tsx` (SceneRenderer·EndingScreen·ChoiceList).
중첩 마크업은 지원하지 않는다 — **토큰끼리 겹치지 말 것**.

| 대상 | 표기 | 렌더 | 예 |
|---|---|---|---|
| 인물명(화자 헤더) | `**이름**` | 굵게 | `**베일 박사**` |
| 지문(무대 지시·서술 강조) | `*…*` | 회색 이탤릭 | `*(떨리는 목소리로)*` |
| 대사·인용 | `"…"` 그대로 | 호박색(가스등 톤) — **자동**, 별도 마크업 금지 | `"만지면 안 됐어."` |
| 장소·아이템·고유 개념 | `[[명사]]` | 청록색, 괄호 미표시 | `[[옴팔로스 정거장]]` |

## 규칙

1. **대사는 큰따옴표만으로 표기한다.** `*"대사"*` 처럼 이탤릭으로 감싸거나 대사 안에
   `*강조*`/`[[…]]` 를 넣지 않는다(따옴표 감지가 우선이라 안쪽 마크업은 원문 노출됨).
   따옴표는 한 문단(줄) 안에서 닫혀야 한다.
2. **희곡체 대사는 2줄**: `**인물명** *(행동 지문)*` 다음 문단에 `"대사"`. 화자는 단일
   인물 또는 단일 집단만("A와 B" 금지) — seed-358 변환 규약과 동일.
3. `[[…]]` 는 처음 언급되거나 서사적으로 중요한 순간에만 — 같은 명사를 문단마다
   태깅하면 소음이 된다. 선택지 라벨의 `[완력]` 같은 홑대괄호 프리픽스는 서식이 아니다
   (그대로 표시됨).
4. 지문 이탤릭 안에 별표 중첩 금지(`*…*연료*…*` ✗) — 토크나이저가 잘못 쪼갠다.
5. 구조 제약(린트): 문단 ≤300자, 본문 합 80~1800자·비엔딩 ≥3문단, 선택지 pool ≤6,
   비엔딩 dead-end 금지. `pnpm verify:web-adventure` 로 확인.

## 인라인 디렉티브 · 동적 치환 (연출 확장)

표시 마크업(`**…**` `*…*` `"…"` `[[…]]`)에 더해, 본문에 **연출 지시**와 **변수 치환**을 끼울 수
있다. 파서 `src/lib/web-adventure/script.ts`(`parseScript`·`interpolate`)가 웹 렌더러와 **앱
플레이어가 공유하는 단일 계약**이다 — 새 디렉티브를 늘릴 땐 이 파서 + 웹(`SceneRenderer`)·앱 렌더러를
함께 갱신할 것. 디렉티브 토큰은 표시 텍스트에 **문자로 노출되지 않는다**.

### `{{변수}}` 치환

`{{키}}` 는 `Character.variables[키]` 값으로 치환된다(본문·선택지 라벨 공통). 소스는 씬 진입 시
`Scene.onEnter.setVars`(`Record<string, string|number>`)로 병합 설정한다. **미정의 키는 원문 그대로
유지**(오작성 방어). 예: 본문 `너는 {{route}}로 스며든다` + `onEnter.setVars: { route: "정문 초소" }`
→ `너는 정문 초소로 스며든다`.

### `<< 디렉티브 >>` 토큰

`[[명사]]`·`{{변수}}` 와 겹치지 않는 **세 번째 괄호**. 문단 임의 위치 또는 단독 라인에 쓴다. `img`·
`fx` 는 **단독 라인 권장**(문단 사이 연출) — 텍스트와 같은 문단에 섞으면 텍스트는 `<p>`, 삽화/효과는
별도 블록으로 분리 렌더된다.

| 디렉티브 | 인자 | 동작 | 상태 |
|---|---|---|---|
| `<<img 이름\|URL [inline\|impact]>>` | 에셋 이름/URL, 모드(기본 `inline`) | 본문 사이 삽화. `inline`=본문폭, `impact`=full-bleed 컷 | ✅ 렌더 구현 |
| `<<fx fadeout\|fadein\|flash\|shake [ms]>>` | 효과, 지속 ms(기본 flash 400·나머지 800) | 화면효과 — fadeout/fadein/flash=전체화면 오버레이, shake=씬 카드 흔들림 | ✅ 렌더 구현 |
| `<<sfx 이름 [vol]>>` | 효과음 에셋, 볼륨 | 효과음 1회 재생 | ⏳ 재생 예정 — 현재는 표시에서 제거만 |
| `<<bgm play\|stop\|pause\|resume [이름] [fade]>>` | 제어, 트랙, 페이드 | BGM 중간 제어 | ⏳ 재생 예정 — 현재는 제거만 |
| `<<wait ms>>` | ms | 리빌 사이 호흡 비트 | ⏳ 미구현(현재 무시) |
| `<<set k=v>>` | `키=값` | 인라인 변수 설정 | ⏳ 미구현 — 대신 `onEnter.setVars` 사용 권장 |

- **에셋 이름/URL**: `img`/`sfx`/`bgm` 의 첫 인자는 에셋 키 또는 URL. 현재 렌더러는 값을 그대로
  `src` 로 쓴다(키→MinIO URL 해석 파이프라인은 오디오 업로드와 함께 도입 예정).
- **씬 기본 BGM**: `Scene.bgm?: { src; loop?; volume? }` 로 씬 단위 배경음을 지정(있/없 선택). 중간
  제어는 `<<bgm …>>`. (재생은 오디오 재생 태스크에서 연결 — 현재 스키마 필드만 존재.)
- **화면효과는 `prefers-reduced-motion` 시 애니메이션 off**(접근성). 오버레이는 pointer-events 없음.

### 하위호환

디렉티브·`{{변수}}` 가 **없는 기존 씬은 렌더가 종전과 100% 동일**하다(파서가 단일 텍스트 세그먼트로
반환). 기존 body-only 씬을 손댈 필요 없이 필요한 씬만 점진 저작한다.

## 선택지 랜덤 노출 (3-of-N)

씬에 선택지를 최대 **6개까지** 저작할 수 있고, 화면엔 **회차마다 3개만 랜덤**으로 뜬다
(`engine/choiceSample.pickDisplayedChoices`). 같은 회차·씬은 항상 같은 조합(안정), 회차가
바뀌면 다른 조합 → 반복 플레이 요인. 저작 시:

- **화면은 항상 3개**다. 6개를 써도 한 화면에 6개가 뜨지 않는다.
- 추첨 대상은 **일반(plain) 선택지**뿐. `conditional`(조건 해금)·`probability`(도전)는
  보이면 **항상 노출**된다(랜덤으로 안 가려짐).
- 핵심 진행/스토리 분기는 `pinned: true` 로 지정해 **항상 노출**시킨다 — 그래야 랜덤으로
  가려져 특정 엔딩·진행이 봉쇄(소프트락)되지 않는다. **매 씬 최소 1개의 진행 경로는
  pinned 또는 conditional/probability 로 보장**할 것.
- 선택지가 3개 이하면 추첨 없이 그대로 전부 노출된다.
- 추가로 넣는 4~6번째 분기는 *의미 있게 다른 전개*로 이을 때 리플레이 가치가 크다
  (단순 flavor 면 유인이 약함).

## 콘텐츠 소스

씬 원문의 소스코드는 `scripts/seed-*.mjs`(Mongo upsert, 멱등)다. 새 씬은 시드 작성 후
**반드시 `scripts/seeds-replay.sh` 의 PATCHES 에 등록**할 것(재해복구 재구축 경로).
