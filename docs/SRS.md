# Software Requirements Specification (SRS)

## 1. 소개

### 1.1 목적

Handmade Site는 사용자들이 유머 게시글을 작성, 공유, 조회하고, 태그와 댓글, 좋아요/싫어요, 업적 시스템을 통해 커뮤니케이션을 즐길 수 있는 웹 애플리케이션입니다.

### 1.2 범위

이 문서는 사이트의 기능 요구사항과 비기능 요구사항을 정의하며, 현재 구현된 설계와 실행 흐름을 반영합니다.

### 1.3 용어 정의

- **사용자(User)**: 사이트를 이용하는 일반 방문자 또는 로그인 사용자
- **게시글(Post)**: 제목, 본문, 태그, 이미지, 작성자 정보를 포함하는 글
- **태그(Tag)**: 게시글 분류 및 검색을 위한 키워드
- **댓글(Comment)**: 게시글에 대한 사용자 의견
- **업적(Achievement)**: 사용자 활동에 따라 자동으로 부여되는 보상

## 2. 사용자 유형

- **비회원**: 게시글 목록/상세 조회, 태그 검색, 익명 댓글 작성
- **회원**: 게시글 작성/수정/삭제, 댓글 작성/삭제, 좋아요/싫어요, 프로필/설정 조회, 업적 확인
- **관리자(미구현)**: 별도 역할 모델은 없으나 향후 확장 가능

## 3. 기능 요구사항

### 3.1 인증

- Google/GitHub OAuth 로그인 지원
- 로그인 사용자만 게시글 작성·수정·삭제, 댓글 작성, 좋아요/싫어요, 프로필/설정 접근 가능

### 3.2 게시글 관리

- 게시글 목록 조회 및 페이징 (최신순/인기순/댓글순 정렬)
- 게시글 상세 보기 (조회수 자동 증가)
- 게시글 작성/수정 (리치 텍스트 에디터, 태그 추가, 이미지 첨부)
- 게시글 수정 시 이전 버전 이력 보존
- 게시글 삭제 (soft delete, 포인트 차감)

### 3.3 태그 기능

- 태그 입력 시 자동완성 지원
- 태그 클릭 시 해당 태그가 포함된 게시글 목록 제공
- 태그 클라우드 페이지에서 전체 태그 탐색

### 3.4 댓글 기능

- 게시글에 댓글 작성 (로그인/비로그인 모두 가능)
- 댓글 삭제 권한은 작성자에게만 부여
- 삭제된 댓글은 내용이 대체 문구로 표시됨

### 3.5 좋아요/싫어요

- 게시글 좋아요/싫어요 처리 (좋아요 수는 0 미만으로 내려가지 않음)

### 3.6 사용자 대시보드

- 본인 게시글 목록 조회
- 업적 목록 및 포인트 현황 확인
- 테마 설정(라이트/다크/시스템) 변경

### 3.7 업적 및 포인트

- 게시글 작성, 댓글 작성 시 포인트 자동 부여
- 게시글 작성 수, 댓글 수, 추천 수 달성 시 업적 자동 부여
- 업적 획득 시 토스트 알림 표시

### 3.8 이미지 업로드

- 에디터 내 이미지 업로드 지원
- 원본 이미지와 썸네일을 함께 저장

## 4. 비기능 요구사항

### 4.1 성능

- 게시글 목록은 페이징으로 초기 로딩 데이터 최소화
- 무한 스크롤로 추가 게시글 로딩
- 이미지는 업로드 전 클라이언트 측 압축 처리

### 4.2 보안

- 인증된 사용자만 민감한 기능 접근 가능
- 게시글/댓글 삭제 시 서버에서 작성자 소유권 검증
- Soft delete로 데이터 즉시 노출 방지

### 4.3 유지보수성

- 기능별 모듈 분리로 변경 영향 범위 최소화
- 도메인 로직은 라이브러리 함수로 재사용 가능하게 구성

### 4.4 접근성

- 키보드 접근성 지원
- 버튼/폼에 적절한 aria 속성 적용

## 5. 주요 사용자 시나리오

### 5.1 게시글 탐색

1. 홈 페이지 진입
2. 최신/인기 게시글 목록 확인, 무한 스크롤로 추가 로딩
3. 게시글 클릭 후 상세 내용 확인

### 5.2 태그별 검색

1. 태그 클라우드 페이지 진입
2. 검색어 입력 후 태그 선택
3. 태그가 포함된 게시글 목록 확인

### 5.3 게시글 작성

1. 로그인 후 글쓰기 페이지 진입
2. 제목, 본문(리치 텍스트), 태그 입력 및 이미지 업로드
3. 제출 후 포인트 획득 및 업적 조건 충족 시 알림 표시

### 5.4 게시글 수정

1. 본인 게시글 수정 페이지 진입
2. 기존 내용 수정 후 저장
3. 이전 버전은 자동으로 이력에 저장

### 5.5 댓글 작성

1. 게시글 상세 페이지에서 댓글 입력
2. 로그인 사용자는 닉네임, 비회원은 익명 ID로 표시
3. 로그인 사용자는 댓글 작성 시 포인트 부여

### 5.6 좋아요 및 업적

1. 게시글 좋아요 클릭
2. 좋아요 수 반영
3. 누적 조건 달성 시 업적 획득 및 알림 표시

## 6. 제약 조건

- Next.js App Router 기반 SSR/클라이언트 컴포넌트 혼용
- MongoDB + Mongoose 기반 데이터 저장
- 이미지 업로드를 위한 MinIO 또는 S3 호환 저장소 필요
- 인증은 Google/GitHub OAuth만 지원
- 게시글/댓글 삭제는 soft delete 방식 사용
- 관리자 기능(신고, 콘텐츠 검수) 미구현
