# MVP 범위

## MVP 한 줄

> *"30~40 씬, 4~6 엔딩, 6 스탯, 단편 30~45 분. 회차 권장."*

## 결정 옵션 (사용자 검토 필요)

### B. 컨텐츠 페이스 비교

| 옵션 | 장점 | 단점 | 운영 부담 | 추천 여부 |
|------|------|------|----------|----------|
| **(1) 단편 30~45 분** | 끝이 있음. 작업량 예측 가능. 회차 보너스로 재플레이 유도 | 한 번 풀고 끝 위험 | 낮음 | ★ **추천** |
| (2) 시즌제 CYOA (Choice of Games 풍) | 장기 운영, 커뮤니티 | 매 시즌 100K+ 단어 제작 필요. 1 인 운영 한계 | 매우 높음 | ✗ |
| (3) idle/무한 | 운영 부담 매우 낮음 | "CYOA" 보다는 *클리커*. 컨셉 충돌 | 매우 낮음 | △ — 컨셉과 거리 |

**추천 근거**:
- 사이트 메인 컨텐츠가 *블로그·재실 감지* 라 게임은 *부수적*. 단편이 fit.
- 모험가 이야기도 1 회 플레이 = 30~45 분이 *정공법*.
- bevy-rogue 의 *짧은 호흡* 과 톤이 어울림.

→ **B. (1) 단편 30~45 분** 채택 권장.

### F. 엔딩 수 비교

| 옵션 | 작업량 | 회차 매력 | 추천 |
|------|--------|----------|------|
| (1) 2~3 엔딩 | 낮음 | 낮음 (2 회면 끝) | △ |
| **(2) 4~6 엔딩** | 중간 | 중간 (회차 3~4 회 자연) | **★ 추천** |
| (3) 8+ 엔딩 | 매우 높음 | 높음 | ✗ — MVP 초과 |

→ **F. (2) 4~6 엔딩** 채택 권장.

### G. 어빌리티 시스템

| 옵션 | 효과 | 추천 |
|------|------|------|
| (1) MVP 미포함 → Post-MVP | 작업량 ↓, 스탯만으로 분기 | △ — 시작 보너스 부족 |
| **(2) MVP 에 3~4 개** | 시작 보너스 + 새 분기축 | **★ 추천** |

→ **G. (2) MVP 에 3~4 개** 채택 권장.

## MVP 범위 (DO)

### 컨텐츠

- **씬 (scene)**: 30~40 개 (씬 = 한 화면 = 일러스트 1 장 + 텍스트 2~5 문단 + 선택지 2~4 개)
- **씬 카테고리**: 광장 / 시장 / 장로의 집 / 숲 입구 / 숲 내부 / 동굴 입구 / 동굴 안 / 산기슭 / 결말 화면 등
- **NPC 5~7 명**:
  - 장로 (메인 의뢰자, bevy-rogue lore 연결)
  - 시장 주인 (구두쇠 박씨, 비밀 간식 숨김)
  - 산신령 (비밀 루트 키)
  - 도깨비 (확률 판정 시험)
  - 행상인 (인벤 교환)
  - 마법사 (지능 판정 + 어빌리티 부여)
  - 동료 (카리스마 판정으로 동행 여부)
- **아이템 10~14 개**: 검 / 횃불 / 빵 / 약초 / 녹슨 열쇠 / 두루마리 / 산신령의 안경 / 도깨비 부적 / 시장 영수증 / 비밀 간식 / 마법서 / 동행 증표
- **메인 퀘스트 1 개**: bevy-rogue *장로의 비밀 간식* 의 텍스트판 → "장로가 시장 주인이 숨긴 비밀 간식 (super_tintham_cracker) 을 부탁한다"
- **엔딩 4~6 종**:
  1. **메인 클리어** — 비밀 간식 장로에게 전달
  2. **비밀 루트** — 산신령 동행, 깨달음
  3. **실패** — 시장 주인 의심 누적 → 마을 추방
  4. **회사원 엔딩** — 모험 포기, 마을 시장에서 정착 (저격받지 않는 평범한 결말)
  5. (선택) **도깨비 친구** — 도깨비 카리스마 판정 성공 + 부적 보유
  6. (선택) **마법사 제자** — 지능 ≥ 8 + 마법서 보유

### 시스템

- **선택지 (3 종)**:
  - *상시 가능* — 모든 플레이어에게 보임
  - *확률 판정* — 버튼 옆 `[힘 65 %]` 표기. 클릭 시 `스탯 + d20 vs 난이도` 판정 → 성공 / 실패 분기.
  - *조건* — 미충족 시 회색 disabled + tooltip (`지혜 7 이상 필요`)
- **스탯 6 개 + 시작 보너스**:
  - 힘 / 민첩 / 지능 / 카리스마 / 건강 / 지혜 (각 기본 5)
  - 시작 시 +1 보너스 분배 (총 합 +5 = 평균 5.8) — 모험가 이야기 대비 *간소화*
  - 진행 중 이벤트 / 아이템으로 ±1~3 증감
- **HP / 건강 분리**: HP 0~100 (피해), 건강 스탯 (=최대 HP 영향: `100 + 건강 × 5`)
- **인벤토리**: 슬롯 6~8 칸 (모험가 이야기보다 가볍게)
- **어빌리티 3~4 개** (MVP 시작 보너스):
  - *학자의 눈* — 지능 판정 +2
  - *전사의 손* — 힘 판정 +2
  - *말솜씨* — 카리스마 판정 +2
  - *행운아* — 모든 확률 판정 1 회 재굴림 (게임당 3 회)
- **저장**: mongo + Firebase Auth 동기화. 비로그인은 localStorage. *회차 별 별도 doc*.
- **회차**: 클리어 시 회차 +1, 이전 회차 엔딩이 *다음 회차 일부 NPC 대사* 에 반영 (`다시 와줬구나`)

### UI

- 도트 일러스트 1 장 (씬마다)
- 씬 묘사 텍스트 (한국어, 2~5 문단)
- 선택지 버튼 2~4 개 (조건 미충족 회색, 확률 % 표시)
- 사이드 패널: 6 스탯 바 / HP / 인벤 아이콘 / 회차 / 어빌리티
- 모바일: 풀스크린 세로 스택, 사이드 패널은 햄버거 토글

## MVP 범위 (DON'T)

- **명령어 입력** (선택지 클릭 only)
- 멀티플레이어 (실시간)
- AI 텍스트 생성 (수동 작성한 분기만)
- 본격 도트 일러스트 의뢰 (MVP 엔 CC0 + Tailwind 색감)
- 음악·사운드 (Post-MVP)
- 친구 목록·랭킹
- 결제·과금
- 영어 번역 (한국어만)

## MVP 측정 기준 ("끝났다" 판단)

1. 신규 유저가 첫 씬 → 엔딩 1 회 도달까지 *손 안 잡고* 30~45 분
2. 회차 1 → 회차 2 진행 시 *다른 엔딩* 도달 가능
3. 비로그인 → 로그인 후에도 진행도 유지 (저장 동기화)
4. 한국어 모바일에서 선택지 클릭 정상 (탭 영역 충분, 가상키보드 영향 X)
5. 한 번 플레이 완료한 사람의 *재플레이율* ≥ 40 % (모험가 이야기 referent → CYOA 는 클릭커 보다 재플레이율 높음)
6. 6 엔딩 중 *최소 3 개* 가 분석 기간 내 도달됨

## Post-MVP (다음 분기 후보)

| 우선순위 | 항목 | 예상 작업 |
|----------|------|----------|
| 높음 | 본격 도트 일러스트 의뢰 (씬당 1 장, 30~40 장) | 4 주 (외주) |
| 높음 | 씬 20 개 추가 (산기슭·바다·왕도) | 3 주 |
| 높음 | 어빌리티 4 개 추가 (총 7~8 개) | 1 주 |
| 중간 | 엔딩 2~3 종 추가 (총 6~8 엔딩) | 2 주 |
| 중간 | 비동기 *흔적* — 다른 유저의 선택 통계 (`이 씬에서 71 % 가 도망쳤다`) | 1 주 |
| 중간 | 업적 시스템 | 1 주 |
| 낮음 | 사운드 (씬 카테고리 별 ambient) | 1 주 |
| 낮음 | 영어 번역 | 2 주 |

## MVP 단어 / 분량 budget

| 항목 | 분량 |
|------|------|
| 평균 씬 텍스트 | 200~400 단어 (한국어 글자 기준 약 400~800 자) |
| MVP 총 씬 수 | 30~40 |
| MVP 총 텍스트 | 약 1.5 ~ 2 만 단어 (한국어 3~4 만 자) |
| 1 회 플레이 노출 텍스트 | 약 6~9 천 단어 (한국어 1.2~1.8 만 자) — 30~45 분 읽기 |
| 비교 — 80 Days | 75 만 단어 (1 회 2 % = 1.5 만 단어) |
| 비교 — Choice of Games 평균 | 100~200 K 단어 |
| 비교 — CYOA 종이책 | 20~30 페이지 (5 천 단어) |

→ MVP 는 *얇은 CYOA 책 4~5 권 분량*. 1 인 6 주에 작성 가능.
