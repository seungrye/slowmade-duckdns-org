# 모험 (Web Adventure) — 기획 인덱스

> 한 줄 요약: *"한국어 텍스트 어드벤처. 선택지 한 번으로 운명이 갈리는 30~45 분 분량. 6 스탯, 다회차, 도트 일러스트."*

기존 사이트(`webapp/`) 의 `bevy-rogue` 와는 **별개의 독립 게임**. bevy-rogue
가 픽셀/wasm 액션이라면, 이쪽은 *선택지 기반 CYOA + 스탯 RPG*.
모델은 **모험가 이야기 (Studio Wheel)** 와 **inkle 의 80 Days / Sorcery!**
를 잇는 *Choose-Your-Own-Adventure + 능력치 판정* 계보.

> 폴더명은 URL/git 일관성을 위해 `web-mud/` 를 그대로 유지함. 내부 내용은 *명령어 입력 머드* 모델을 완전 폐기하고 *선택지 + 스탯 RPG* 로 재정의됨.

## 핵심 모델 (모험가 이야기 기준)

- **입력**: 선택지 클릭 (명령어 입력 X)
- **스탯 6 개**: 힘 / 민첩 / 지능 / 카리스마 / 건강 / 지혜
- **선택지 종류 3 가지**:
  - *상시 가능* — 누구나 고를 수 있음
  - *확률 판정* — 스탯 + d20 vs 난이도 (예: 힘 65%)
  - *조건* — 특정 스탯 ≥ N / 아이템 보유 / 어빌리티 보유 시만 활성
- **그래픽**: 감성 도트 일러스트 (MVP 에선 공개 CC0 자산 + Tailwind 색감, 본격 도트는 Post-MVP)
- **결말**: 4~6 종 엔딩. 선택과 스탯이 에필로그에 반영
- **회차**: 다회차 권장. 다른 선택 → 다른 길 → 다른 엔딩

## 사용자가 결정해야 할 옵션 (재정의)

| 결정 | 선택지 | 추천 |
|------|--------|------|
| **A. 입력 모델** | (1) 명령어 입력 / (2) 선택지 클릭 / (3) 하이브리드 | **(2) 선택지 클릭** — 모바일 친화, CYOA 표준 (확정) |
| **B. 컨텐츠 페이스** | (1) 단편 30~45 분 / (2) 시즌제 / (3) idle | **(1) 단편** — 회차 3~4 회 분기 (확정) |
| **C. 세계관** | (1) 한국형 판타지 / (2) bevy-rogue 연결 / (3) 모던 한국 | **(2) bevy-rogue 연결** — *장로의 비밀 간식* 텍스트판 (확정) |
| **D. 기술 스택** | (1) 클라이언트 only / (2) WebSocket / (3) Server Action | **(3) Server Action + Mongo** — 사이트 일관성 (확정) |
| **E. 그래픽 톤** | (1) ASCII only / (2) 공개 도트 CC0 / (3) 본격 의뢰 도트 | **(2) MVP 공개 도트 → (3) Post-MVP 의뢰** |
| **F. 엔딩 수** | (1) 2~3 / (2) 4~6 / (3) 8+ | **(2) 4~6** — 다회차 매력 vs 작업량 균형 |
| **G. 어빌리티 시스템** | (1) Post-MVP / (2) MVP 에 3~4 개 | **(2) MVP 에 3~4 개** — 스탯과 별개 분기축 추가 |

각 결정의 *왜*와 *대안* 비교는 해당 문서 참조.
