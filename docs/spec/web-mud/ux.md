# 화면 / UX

## 디자인 톤

- **양피지 베이지 배경** (`#f4ead5` ~ `#e8dcb5`) + 다크 텍스트 (`#2b2419`)
- 라이트 모드 only (MVP) — 다크 모드는 Post-MVP (양피지 톤 보존 어려움)
- **도트 일러스트** 카테고리별 색감 — 광장은 새벽 보라, 숲은 청록, 동굴은 황색
- **폰트**: 한국어 *둥글림 sans-serif* — Pretendard 우선, Nanum Square fallback. 본문 16~18 px, 선택지 18~20 px.
- 강조색:
  - *NPC* — 단청 살구 (`#c9683d`)
  - *아이템* — 청록 (`#3a8c8c`)
  - *판정 성공* — 짙은 녹 (`#5a8a3f`)
  - *판정 실패* — 벽돌 빨강 (`#a64b3a`)

### 데스크탑 핵심

- 좌측 *메인 영역* (8 컬럼): 일러스트 + 텍스트 + 선택지
- 우측 *사이드 패널* (4 컬럼): 6 스탯 바 + HP + 어빌리티 + 인벤 + 회차
- 일러스트는 *씬당 1 장 고정*. 16:9 비율.
- 선택지 버튼은 *세로 스택* — 클릭 영역 넓게.

### 모바일 UX 핵심

- 일러스트 → 텍스트 → 선택지 *세로 스택*
- 사이드 패널은 햄버거 토글 (`≡`)
- 상단 HP 만 노출 (위험 상태 빨강 표시)
- 선택지 버튼 최소 높이 56 px (탭 영역 확보)
- 가상 키보드 미사용 (입력창 없음 → 모바일 친화)

## 선택지 UX 상세

### 1. 상시 가능 (always)

```
┌────────────────────────────────────────┐
│ 1. 장로의 집으로 간다                  │
└────────────────────────────────────────┘
```

- 양피지 베이지 + 짙은 테두리
- 클릭 시 hover → 살짝 어두워짐

### 2. 확률 판정 (roll)

```
┌────────────────────────────────────────┐
│ 4. 노파에게 말을 건다   [카리 65 %]    │
└────────────────────────────────────────┘
```

- 우측에 *스탯 키 + 성공률* 표기
- 어빌리티 보정 반영된 *실제* 성공률
- 클릭 시 *주사위 굴림 애니메이션* (1 초) → 성공/실패 텍스트 표시

### 3. 조건 미충족 (conditional, 회색)

```
┌────────────────────────────────────────┐
│ ⊘ 동굴로 간다           [횃불 필요]    │
└────────────────────────────────────────┘
```

- 양피지 흐릿 + `⊘` 아이콘
- 회색 글자
- hover → tooltip `횃불을 보유하고 있어야 합니다.`

### 4. 조건 미충족 (숨김)

- 표시 자체 X (`hideIfFail: true` 인 비밀 선택지)
- 다회차 / 빌드 학습 유도

## 일러스트 가이드

### MVP — 공개 CC0 자산 활용

- *씬당 1 장* 16:9 비율, 768 × 432 px (또는 1024 × 576)
- 카테고리 별 톤:
  - 광장 → 새벽 보라/주황 (`#9b7ec7`)
  - 시장 → 따뜻한 황금 (`#d4a557`)
  - 숲 → 짙은 청록 (`#2d6a5c`)
  - 동굴 → 어두운 황 (`#7a5d2c`)
  - 산기슭 → 푸른 회색 (`#5a7589`)
- *없는 씬* 은 *카테고리 디폴트* 일러스트 재사용 + 텍스트 강조
- 추천 CC0 출처:
  - [itch.io CC0 Pixel Art](https://itch.io/game-assets/free/tag-cc0/tag-pixel-art)
  - [PIPOYA RPG Character Sprites](https://pipoya.itch.io/)
  - [5600+ Pixel Art Fantasy RPG Icons (Clockwork Raven)](https://clockworkraven.itch.io/5600-ultimate-pixel-art-fantasy-rpg-icon-pack)

### Post-MVP — 본격 의뢰 도트

- 외주: 씬당 30~50 USD × 30~40 씬 = 약 1,000~2,000 USD
- 한국 도트 일러스트레이터 / itch.io 작가 직접 컨택
- 스타일 referent: *Roadwarden*, *모험가 이야기*, *Stardew Valley*

## 사이드 패널 구성 (데스크탑) / 햄버거 (모바일)

| 섹션 | 내용 |
|------|------|
| 스탯 | 6 스탯 바 차트 (1~15 범위, Choice of Games `stat_chart` 스타일) |
| HP | 진행 바 + 숫자 (위험 시 빨강) |
| 어빌리티 | 시작 시 선택한 1 개 + 효과 설명 |
| 가방 | 인벤 슬롯 그리드 (6~8 개, 도트 아이콘) |
| 회차 | 현 회차 번호 + 이전 회차 엔딩 |
| 메뉴 | 엔딩 갤러리 / 회차 초기화 / 도움말 |

## 색상 시스템 (Tailwind variable)

```css
/* 양피지 톤 */
--adv-bg-parchment: oklch(0.92 0.04 80);     /* #f4ead5 */
--adv-bg-card:      oklch(0.88 0.05 75);     /* #e8dcb5 */
--adv-fg-text:      oklch(0.20 0.02 60);     /* #2b2419 */
--adv-border:       oklch(0.50 0.08 60);     /* 어두운 갈색 */

/* 강조색 */
--adv-npc:          oklch(0.55 0.15 35);     /* 단청 살구 */
--adv-item:         oklch(0.55 0.10 195);    /* 청록 */
--adv-stat-bar-fill: oklch(0.55 0.08 60);    /* 황토 */
--adv-success:      oklch(0.55 0.12 130);    /* 짙은 녹 */
--adv-fail:         oklch(0.50 0.15 25);     /* 벽돌 빨강 */
--adv-disabled:     oklch(0.65 0 0);         /* 회색 */

/* 선택지 버튼 */
--adv-btn-bg:       var(--adv-bg-card);
--adv-btn-bg-hover: oklch(0.82 0.05 75);
--adv-btn-border:   var(--adv-border);
```

## 접근성

- 색만으로 의미 표현 금지 — 아이콘 + 색 + 텍스트 라벨
- 키보드 조작: 숫자 키 1~4 로 선택지 즉시 선택
- `aria-live="polite"` 본문 → 스크린리더 새 씬 알림
- 폰트 크기: 사이트 설정 (rem) 상속
- 색약 모드: Post-MVP — 성공/실패 아이콘 (✓/✗) 부여

## 엔딩 / 에필로그 화면

```
┌───────────────────────────────────────┐
│                                       │
│  [엔딩 일러스트 — 메인 클리어]        │
│                                       │
└───────────────────────────────────────┘

[메인 엔딩 — 장로의 약속]

장로는 미소 지으며 비밀 간식을 받았다.
"이것이 정말 그것이로군. 자네는 약속을 지켰네."

당신의 모험은 이렇게 끝났다.

  ─── 통계 ───
  플레이 시간: 38 분
  씬 본 갯수: 22 / 35
  실패한 판정: 3 회
  획득 아이템: 7 종

[다시 도전 (회차 3)]    [엔딩 갤러리]
```

## 엔딩 갤러리

- 회차 누적 *달성 엔딩* 목록
- 미달성 엔딩은 *? ? ?* 표시 + 힌트 한 줄
- 클릭 시 *해당 엔딩 에필로그* 다시 읽기

## 에러 / 빈 출력

- 모든 선택지 조건 미충족 → "이 곳에서 할 수 있는 일이 없다." + 1 개 *복귀* 선택지 강제 표시
- 서버 에러 → `[시스템] 연결이 끊겼습니다. 다시 시도하세요.` + 재시도 버튼

## 진행 UI 디테일

- 씬 전환 시 *페이드 + 슬라이드* 애니메이션 (300 ms)
- 일러스트 로드 중 placeholder (단색 양피지)
- 본문 텍스트 *타이핑 효과* (옵션 — 기본 OFF, 설정에서 ON)
- 자동 스크롤 (모바일에서 일러스트 → 선택지로)
- 사이드 패널 스탯 변화 시 *짧은 펄스* (500 ms 강조)
