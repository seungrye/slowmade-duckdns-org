## VR 을 원문 규격에 맞춘다 (#345)

라오어 VR 방법론 **원문 카페글**(방법론 개요·백테스트 3부작·인출식VR 등)과 우리 구현을
한 줄씩 대조했다.

## 먼저 — 핵심 수식은 맞다

가장 미묘한 지점이 정확히 맞춰져 있었다.

- 원문: *"이번 사이클이 끝나고 V = 9000$, pool = 1000$ 인 상태였다"* → *"다음V = 현재V +
  1000/10 + 250 = 9350"* → **V 는 CF 반영 _전_ pool 로 계산**
- 원문: *"적립**후** pool 의 75%", "인출**후** pool 의 25%"* → **한도는 CF 반영 _후_ pool**

구현이 `advanceCycleVR` 에서 이 둘을 갈라 쓴다. `V₂=V₁+Pool/G±CF`·밴드 `V(1±0.15)`·매매
3규칙·매도 평단 무관·첫 V=매수 직후 평가금도 모두 원문 그대로다.

## 원문 백테스트를 재현한다

거치식·TQQQ·2011~2020·±15% 로 원문 표와 대조(`vr-reference.test.ts`):

| G | CAGR 우리/원문 | MDD 우리/원문 | 평균 P/V 우리/원문 |
|---|---|---|---|
| 10 | 47.41 / 49.47 | −61.17 / −58.41 | 0.1459 / 0.1521 |
| 20 | 44.85 / 46.16 | −57.17 / −55.72 | 0.2663 / 0.2725 |
| 30 | 42.45 / 44.12 | −54.15 / −52.48 | 0.3669 / 0.3780 |
| 40 | 40.34 / 41.86 | −51.69 / −50.03 | 0.4533 / 0.4672 |

TQQQ 올인 MDD 가 −69.92% 로 **원문과 소수점까지 일치** — 같은 데이터라는 뜻이다.

차이는 **전부 한 방향**이다(우리가 수익 낮고·낙폭 크고·현금 얇다). 원인은 하나로 설명된다 —
원문은 **1주씩 지정가 사다리**로 장중 체결하는데 우리는 종가에 한 번에 산다. 비싸게 사면
Pool 을 더 쓰고 → P/V 가 낮아지고 → 상승률이 작아져 → 수익↓·낙폭↑. 즉 우리 백테스트는
**일관되게 보수적으로 과소평가**한다. 사다리는 별건으로 남긴다.

## 고친 것

**① Pool 한도·G 를 운용 형태에서 유도** — 원문 7.1 표(적립 10/75% · 거치 10/50% ·
인출 20/25%). 예전엔 `poolLimitPct` 가 늘 0.5 라 **적립식인데 거치식 한도로 돌았다.**
원문이 "가이드일 뿐이며 선택 가능" 이라 했으므로 설정에 적으면 그 값이 이기고, **안 적었을
때만** 형태를 따른다.

**② 실효평단을 낸다** — 원문 4.2 `(누적매수 − 누적매도) / 보유수량`. `cumBuy`·`cumSell` 을
수식대로 쌓아 두고도 결과에 안 실었다. 마이너스가 되면 원문 4.3 의 "원금 ZERO 상태"다.

**③ 손익 이름을 갈랐다** — `totalPnl` 이 전략마다 뜻이 다르다. 무한매수·로테이션·듀얼모멘텀은
**매도 실현손익 합계**, VR·변동성타깃은 **최종자산 − 투입원금(평가손익 포함)**. 같은
「실현손익」으로 부르면 전략끼리 비교가 어긋나서, 화면이 이름을 갈라 붙인다.

## 확인 불가 — 원문이 유료로 이동

cover-sell(인출충당 매도) 대금이 그 사이클 `Pool/G` 에 섞여 V 를 올리는 문제. 인출식 원문이
*"자세한 방법설명 및 중계는 팬딩에서 진행하게 됩니다"* 로 끝나, 공개 자료에서 얻을 수 있는
것은 **G=20 · Pool 25% 한도까지**다. 동작을 바꾸지 않고 주석으로만 남긴다.
