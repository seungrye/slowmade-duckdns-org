## 운영 리스크

### 1. 결제 등록 필요

이미지 모델은 **무료 등급 없음**. 현재 사이트가 Free Tier 이면 결제 카드 등록 + Tier 1 활성화 단계 필요.

### 2. 모델 deprecation 주기

- Imagen 3 (`imagen-3.0-generate-002`) 가 1년 만에 종료된 사례 → 모델 ID 를 코드에 hardcode 하지 말 것
- env (`ENJI_IMAGE_MODEL`) 로 빼서 무중단 교체 가능하게
- 분기마다 [release notes](https://ai.google.dev/gemini-api/docs/changelog) 확인

### 3. 콘텐츠 안전

- **사용자가 prompt 입력 → 부적절 요청 가능성**
  - 예: 폭력, 성적 콘텐츠, 유명인 합성
- Google 측 1차 필터: 거부 시 명시 에러 없이 빈 응답 가능 → **fallback 텍스트 메시지** 필요
  - 예: "죄송해요, 그 요청은 처리할 수 없어요."
- 사이트 측 2차 필터 (선택):
  - 단순 keyword block list (한국어 욕설/위험 키워드)
  - 또는 LLM (`gemini-2.5-flash`) 으로 prompt 사전 검사 — 비용 약간 추가

### 4. SynthID 워터마크 — 한국 법규

- 모든 출력에 SynthID 자동 — 한국 "생성형 AI 결과물 표기" 권고 부합
- 추가로 댓글 UI 에 "✨ AI 생성 이미지" 라벨 표시 권장

### 5. 응답 시간

- Nano Banana 3~8초 → 기존 폴링(2초 간격, 30초 데드라인) 안에 충분
- 단, 트래픽 폭주 시 Google 측 큐잉으로 20초+ 가능 → 폴링 데드라인 60초로 확장 검토

### 6. 이미지 저장 비용

- PNG 평균 500KB~2MB
- MinIO 디스크: 월 1,500장 × 1.5MB = 2.25 GB/월 → 무시 가능
- 단, 영구 보존 vs 30일 자동 삭제 정책 결정 필요

### 7. 저작권 / 책임

- Google AI 출력물의 저작권은 사용자 (운영자) 에게 귀속 (Terms of Service 확인 필요)
- 단, **타인 캐릭터/유명인 닮은 생성물** 은 사용자 책임
- 운영자 면책: 약관에 "사용자가 생성한 이미지에 대한 법적 책임은 사용자에게 있음" 명시 권장

### 8. 어뷰징 시나리오

| 어뷰징 | 대응 |
|---|---|
| 봇이 대량 호출 | 로그인 사용자 한정 (이미 적용) + 유저별 일일 한도 |
| 부적절 prompt 반복 | block list + IP 임시 차단 |
| 비용 폭주 (해킹된 계정) | 일일 한도 + Google 콘솔 billing alert |
