# Handmade Site Documentation

이 문서 집합은 `site` 프로젝트의 요구사항 정의서(SRS), 시스템 설계서(SDS), 아키텍처 문서를 포함합니다.

문서 목록:

- `SRS.md` - 소프트웨어 요구사항 명세서
- `SDS.md` - 시스템 설계서
- `architecture.md` - 아키텍처 개요 및 기술 스택

## 목적

이 문서는 프로젝트의 기능 요구사항, 데이터 구조, 아키텍처와 구현 방향을 명확히 하기 위한 기준 자료입니다.

## 사용 방법

1. 개발자는 `SRS.md`를 통해 요구사항과 사용자 시나리오를 확인합니다.
2. 설계자는 `SDS.md`에서 데이터 모델, API, UI 컴포넌트 구조를 참고합니다.
3. 아키텍처 팀 또는 리뷰어는 `architecture.md`를 통해 전체 플랫폼 구조와 기술 선택을 이해합니다.
